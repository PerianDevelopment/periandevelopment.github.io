Overview

{{data.title}} is a website created as a resource for Hytale, specifically focused on the different tree types found throughout the game. The goal was to create a simple, useful reference that players can quickly access while playing, without having to search through wikis or other scattered information.

The website provides detailed information about each of the 30+ tree types, making it easy for players to find the information they need to grow and harvest trees effectively:

  • The wood type, log texture and tree appearance
  • Growth requirements like the required station level, sapling price, required spacing or soil depth
  • All items players can expect to obtain from harvesting a fully grown tree
  • Any other relevant details about each tree type, like unique properties or behaviors

Data collection

The tree data was collected by Hytale Engineer, who created a YouTube Video about the data, with a plain spreadsheet linked underneath. I build the website based on this data and added, unified, and trimmed the information to fit.

Design & UX

I wanted the interface to stay clean and simple, while still making the information easy to scan, which is solved by a search bar with filtering to quickly find the tree you are looking for. The website is also fully responsive and works well on mobile devices, so players can access it while playing the game.

I chose the Cinzel Google Font, since it matches the fantasy aesthetic in Hytale and is easy to read. The color scheme is based on the Hytale brand colors, with the primary hex #456BA9.

Tech & Build Notes

  • 30+ tree types
  • Plain HTML, CSS and JavaScript
  • Tree data in JSON file
  • Hosted on GitHub Pages
  • I used AI to help speed up parts of the project. But the core implementation is my work

Final Result

This project was a fun way to combine my interest in Hytale with building a practical tool that I actually use myself while playing.
