Overview

{{data.title}} is the updated and improved version of the Train Lovers project for the Game Polishing lecture. Together with Julius, I decided to continue working on the project. We renamed it to {{data.title}}, split the tasks between us, and focused on improving the game in preparation for the Game Exhibition.

My role in this project was to implement the settings and menus, as well as integrate the user interface into the 3D environment. The goal was to make the game feel more visually polished and ready for the exhibition.

Branding & Marketing

Julius focused mainly on the branding and marketing material for the game. He created the logo, multiple banners and posters, and organized our appearance at the game exhibition, which was a great success!

Start Screen

The first change i made was to the start screen, which was extremely underwhelming previously. I decided that a simple circular track with the train continuously driving around it would provide visual interest and immediately draw attention.

It was important that the start screen looked appealing, since it's the first thing players see at the game expo and we have to compete with a lot of other games. If our game doesn't stand out, many visitors won't even give our game a chance.

Level Selection

The level selection screen used to be a few static buttons. The new 3D design integrates the levels into the game environment, providing a more immersive experience. The selected level is spinning and the stars are hovering above it. The navigation in between levels is also improved with smooth animations and a simple and intuitive control scheme.

These changes made the level selection more engaging and enjoyable for players. Some players who had already completed all levels with three stars even ended up watching the menu animations after finishing the game!

New Level Selection

Settings

The settings were added from scratch to the game, since the previous version did not have this feature. This included localising all interfaces and menus using Unity's Localization Package.

All settings are fully functional and save between sessions.

Final Result

The final result is a significantly improved version of the game with a more immersive 3D environment, enhanced level selection, and fully functional settings. I am very happy with the outcome and the improvements made.
